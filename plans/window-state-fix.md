# 窗口状态修复计划

范围：保存和恢复主窗口普通尺寸、位置；恢复时约束至当前屏幕可用工作区，解决打包应用窗口过大或离屏的问题。

需求来源：用户反馈“打包后不会记忆上次的窗口大小；超过屏幕应有限制，否则到屏幕外找不到”。

验收依据：[窗口状态验收标准](../docs/window-state-acceptance.md)。窄范围系统窗口修复，不新增产品界面或设计稿。

执行约束：不擅自启动项目；不提交。每项未执行的真实桌面验证保持“待验证”，不能以纯逻辑单元测试替代。

范围限制：不新增程序坞无窗重建；现有插件全屏期间普通尺寸覆盖风险保留为已知限制。两项不作为本次修复准出条件。

最终记录：README 已补充相关功能说明；完整 Rust 测试因离线缺少 `fastrand v2.3.0` 未运行。代码和已执行自动化范围产品验收通过，可以进入真实打包桌面验收，尚不代表完整实际体验或发布验收通过。
