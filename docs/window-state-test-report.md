## 启动与事件接线审查

1. `tauri.conf.json` 主窗口隐藏创建，默认 1000 × 720。
2. `lib.rs:134` 注册限制状态；窗口插件跳过 main 自动恢复且 flags 不包含 VISIBLE；`lib.rs:185` setup 显式调用恢复。
3. `window_state.rs:16` 顺序为普通尺寸／位置恢复 → 无效或错误时默认回退 → 工作区限制 → 最大化／全屏恢复 → 显示。恢复失败只记录日志，不使 setup 返回错误。
4. `window_state.rs:55` 接受移动、缩放、比例变化，关窗和失焦显式保存；`constrain` 使用当前屏幕、无当前屏幕时回主屏，工作区为空时跳过。原生 setter 仅在值变化时调用，互斥锁 `try_lock` 阻止同步重入。
5. 移动事件不强制改变位置，保持跨屏拖动；恢复、缩放及比例变化才纠正位置。持续拖动的系统行为需要桌面验证。
