## 五、测试执行指南

### 5.1 运行 Rust 单元测试

```bash
cd src-tauri
cargo test --package minidoc-app-lib
```

### 5.2 运行前端测试

```bash
# 安装测试依赖
npm install --save-dev jest ts-jest @testing-library/react @testing-library/jest-dom @testing-library/user-event identity-obj-proxy

# 运行测试
npm test

# 运行测试并生成覆盖率报告
npm test -- --coverage
```

### 5.3 运行 E2E 测试

E2E 测试需要真实的 Tauri 环境：

```bash
# 在 Tauri 开发环境中运行
npm run tauri dev
# 然后在另一个终端运行测试
npm run test:e2e
```
