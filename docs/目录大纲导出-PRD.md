## 一、功能概述

### 1.1 功能背景
用户在编辑长文档（如技术文档、书籍章节、API 文档）时，需要快速浏览和分享文档结构。当前 Minidoc 已支持大纲视图，但无法将目录结构导出为独立文件进行分享或打印。

### 1.2 功能定义
用户可以将当前编辑的 Markdown 文档的目录大纲（基于 H1-H6 标题层级）导出为独立文件，支持多种格式（Markdown、TXT、JSON）以便在不同场景下使用。

### 1.3 核心价值
| 受益角色 | 使用场景 | 获得价值 |
|---------|---------|---------|
| 技术文档作者 | 编写 API 文档、技术手册 | 快速生成导航目录供读者预览 |
| 书籍编写者 | 撰写电子书、教程 | 生成章节目录用于目录页 |
| 内容创作者 | 撰写博客、长文 | 生成内容大纲用于分享 |
| 团队协作者 | 文档评审、内容审核 | 快速了解文档结构 |

### 1.4 功能定位
- **入口**: 导出对话框 (ExportDialog)
- **依赖**: Markdown 标题解析能力
- **优先级**: P1（重要功能）

## 二、用户故事

### 用户故事 1: 技术文档作者快速生成导航目录

**故事描述**:
> 作为一个技术文档作者，我正在编写一份 50 页的 API 参考文档，想要在文档开头添加一个可点击的导航目录，方便读者快速跳转到对应章节。

**使用流程**:
```
1. 打开 API 文档
2. 点击导出按钮 (Cmd+E)
3. 选择"目录大纲"格式
4. 选择导出格式为 Markdown（含锚点链接）
5. 点击"复制"按钮
6. 粘贴到文档开头
```

**验收标准**:
- [ ] 导出的 Markdown 目录包含正确的缩进层级
- [ ] 每个目录项包含可点击的锚点链接（如 `[简介](#简介)`）
- [ ] 复制的内容可以直接粘贴到 Markdown 文档中使用

### 用户故事 2: 书籍编写者生成纯文本目录

**故事描述**:
> 作为一个书籍编写者，我需要生成一个纯文本格式的目录，用于邮件发送给编辑预览书籍结构，不需要任何 Markdown 格式。

**使用流程**:
```
1. 打开书籍草稿
2. 点击导出按钮
3. 选择"目录大纲"格式
4. 选择导出格式为 TXT（纯文本）
5. 选择"包含标题编号"（可选）
6. 点击"导出文件"或"复制"
```

**验收标准**:
- [ ] TXT 格式使用空格缩进表示层级（每级 2 个空格）
- [ ] 不包含 Markdown 符号（如 #、*、[] 等）
- [ ] 可选择是否添加标题编号（1. 1.1 1.1.1）

### 3.2 功能详细设计

#### F-01: 目录大纲解析

**功能描述**: 从当前 Markdown 文档中提取所有标题行，构建层级树结构。

**处理逻辑**:
1. 逐行扫描 Markdown 内容
2. 识别 `#` 开头的行（1-6 个 `#` 对应 H1-H6）
3. 提取标题文本，去除 `#` 符号和前导/尾随空格
4. 生成包含层级、标题文本、行号的树结构

**数据结构**:
```typescript
interface TOCItem {
  level: number;           // 1-6，对应 H1-H6
  text: string;            // 标题文本
  line: number;            // 原始行号
  id: string;              // 生成的锚点 ID
  children: TOCItem[];     // 子标题
}
```

**示例**:
输入 Markdown:
```markdown
# 第一章
## 1.1 概述
## 1.2 背景
### 1.2.1 历史
# 第二章
```

输出结构:
```
第一章 (line:1)
├── 1.1 概述 (line:2)
├── 1.2 背景 (line:3)
│   └── 1.2.1 历史 (line:4)
第二章 (line:5)
```

---

#### F-02: 多种导出格式

**Markdown 格式**（默认推荐）:
- 使用 `-` 表示列表项
- 每级缩进 2 个空格
- 包含锚点链接

示例输出:
```markdown
- [第一章](#第一章)
  - [1.1 概述](#11-概述)
  - [1.2 背景](#12-背景)
    - [1.2.1 历史](#121-历史)
- [第二章](#第二章)
```

**TXT 格式**（纯文本）:
- 无 Markdown 符号
- 使用空格缩进表示层级
- 可选标题编号

示例输出:
```
第一章
  1.1 概述
  1.2 背景
    1.2.1 历史
第二章
```

**JSON 格式**（结构化数据）:
- 完整的层级结构
- 包含元数据（行号、锚点 ID）
- 适用于程序化处理

示例输出:
```json
{
  "title": "文档大纲",
  "sourceFile": "document.md",
  "generatedAt": "2026-03-28T10:30:00Z",
  "toc": [
    {
      "level": 1,
      "text": "第一章",
      "line": 1,
      "id": "第一章",
      "children": [
        {
          "level": 2,
          "text": "1.1 概述",
          "line": 2,
          "id": "11-概述",
          "children": []
        }
      ]
    }
  ]
}
```

#### F-03: 一键复制

**功能描述**: 点击复制按钮，将生成的目录内容复制到系统剪贴板。

**交互设计**:
- 复制成功后显示 Toast 提示："已复制到剪贴板"
- 复制按钮显示复制图标，hover 时显示工具提示

**边界处理**:
- 复制失败时显示错误提示："复制失败，请手动选择复制"
- 浏览器权限被拒绝时引导用户手动复制

---

#### F-04: 导出文件下载

**功能描述**: 点击导出按钮，下载目录文件到本地。

**文件命名规则**:
```
<原始文件名>-outline.<格式扩展名>
```

示例:
- `API 文档-outline.md`
- `用户手册-outline.txt`
- `技术规格-outline.json`

---

#### F-05: 导出选项配置

**配置项列表**:

| 配置项 | 类型 | 默认值 | 描述 |
|-------|------|--------|------|
| 最大层级 | 下拉选择 | H6 | 可选择只导出到指定层级 |
| 包含标题编号 | 开关 | 关闭 | 是否为每个标题添加编号 |
| 显示行号 | 开关 | 关闭 | 是否在目录中显示原始行号 |
| 缩进方式 | 单选 | 空格 | 空格/Tabs |

**配置 UI 位置**: 导出对话框底部，导出按钮上方

### 5.1 边界情况列表

| 编号 | 场景 | 处理方式 | UI 反馈 |
|-----|------|---------|--------|
| E-01 | 文档为空 | 禁用导出按钮，显示空状态提示 | "当前文档为空" |

| E-03 | 只有 H1 标题 | 正常导出单层目录 | 正常显示 |

### 5.3 容错设计

1. **Markdown 解析容错**:
   - 行首有多个 `#` 但超过 6 个：忽略该行
   - `#` 后面没有空格：忽略该行（不符合 Markdown 语法）
   - 标题在代码块内：不解析为标题

2. **复制功能容错**:
   - 优先使用 `navigator.clipboard.writeText()`
   - 降级方案：创建隐藏的 `<textarea>`，执行 `document.execCommand('copy')`

3. **下载功能容错**:
   - 优先使用 `<a download>` 触发下载
   - 降级方案：`window.open()` 在新窗口打开内容
